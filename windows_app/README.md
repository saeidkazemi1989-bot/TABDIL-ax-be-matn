# TABDIL — برنامه ویندوزی تبدیل عکس به اکسل و ورد

عکس صفحات **تایپی (جدول، لیست قطعات، فاکتور)** یا **دست‌نویس (یادداشت، نامه)** را می‌دهید و خروجی می‌گیرید:

- صفحات جدولی → **Excel (.xlsx)** یا **Word جدول‌دار (.docx)** — انتخاب با خودتان
- صفحات متنی/دست‌نویس → **Word پاراگرافی (.docx)** یا **Excel سطری (.xlsx)** — انتخاب با خودتان
- **همه خروجی‌ها با فونت Calibri و راست‌به‌چپ (RTL)**
- هر عکس می‌تواند یک شیت جداگانه در اکسل باشد
- نتیجه قبل از ذخیره، داخل خود برنامه **قابل ویرایش** است (سلول‌به‌سلول)
- چرخش خودکار عکس (۰/۹۰/۱۸۰/۲۷۰)، صاف‌کردن کجی، برش خودکار جدول، حذف خطوط جدول برای OCR بهتر
- دو موتور OCR: **Tesseract** (سبک و پیش‌فرض، آفلاین) و **PaddleOCR** (دقیق‌تر، نصب اختیاری)

> نکته: تشخیص متن تایپی دقیق است؛ دست‌خط فارسی ذاتاً سخت‌تر است و نتیجه باید مرور/ویرایش شود.

## نصب یک‌کلیکی (ویندوز)

1. پوشه `windows_app` را روی ویندوز کپی کنید.
2. روی **`Install.bat`** دوبار کلیک کنید.
   - پایتون ۳.۱۰ یا بالاتر در صورت نبود، خودکار نصب می‌شود (با winget).
   - کتابخانه‌ها در یک محیط مجازی نصب می‌شوند.
   - موتور Tesseract OCR خودکار نصب می‌شود (داده زبان فارسی/انگلیسی داخل برنامه همراه است).
   - یک آیکون میانبر **TABDIL** روی دسکتاپ ساخته می‌شود.
3. برنامه را با **`Run-TABDIL.bat`** یا میانبر دسکتاپ اجرا کنید.

پیش‌نیازها: ویندوز ۱۰/۱۱ و اینترنت فقط در مرحله نصب.

برای عیب‌یابی، فایل **`Check-Installation.bat`** را اجرا کنید — نسخه‌ها و وضعیت نصب را نشان می‌دهد.

### مشکل Tesseract پیدا نشد (رایج در ویندوز)

اگر بعد از `Install.bat` همچنان خطای `Tesseract NOT found` دیدید:

1. **`Install-Tesseract.bat`** را اجرا کنید — هم winget هم دانلود مستقیم را امتحان می‌کند.
2. اگر نشد، دستی از https://github.com/UB-Mannheim/tesseract/wiki نصب کنید.
3. اگر Tesseract نصب است ولی برنامه پیدا نمی‌کند: روی "شروع تشخیص" بزنید، برنامه از شما می‌خواهد مسیر `tesseract.exe` را دستی انتخاب کنید (مثلاً `C:\Program Files\Tesseract-OCR\tesseract.exe`) — مسیر ذخیره می‌شود.

فایل **`TROUBLESHOOTING.md`** راهنمای کامل فارسی دارد.

## موتور دقیق‌تر PaddleOCR (اختیاری)

برای دقت بیشتر، مخصوصاً دست‌نویس و جدول‌های کم‌کیفیت‌تر:

1. فایل **`Install-PaddleOCR.bat`** را اجرا کنید (حدود ۱ گیگابایت دانلود).
2. در برنامه از بالای پنل تنظیمات، موتور را روی «دقیق (PaddleOCR)» بگذارید.
3. اولین پردازش چند دقیقه مدل دانلود می‌کند؛ بعد از آن آفلاین است.

### ⚠️ مشکل رایج در ایران (مهم)

مدل‌های PaddleOCR از سرور **Baidu (paddleocr.bj.bcebos.com)** دانلود می‌شوند که در ایران اغلب **فیلتر یا بسیار کند** است. اگر برنامه روی پیام **«در حال آماده‌سازی موتور تشخیص...»** می‌ماند، دلیل همین است.

**راه‌حل‌ها:**

- **با VPN** فایل **`Download-PaddleModels.bat`** را اجرا کنید تا مدل‌ها از قبل دانلود شوند (۲۰۰-۴۰۰ مگابایت).
- یا با VPN یک بار «شروع تشخیص» را بزنید — اولین بار چند دقیقه طول می‌کشد.
- اگر VPN ندارید، از **موتور سبک (Tesseract)** استفاده کنید که کاملاً آفلاین است و برای جدول‌های تایپی دقت بسیار خوبی دارد.
- اگر دانلود ناقص انجام شده، این پوشه‌ها را حذف کنید و دوباره با VPN تلاش کنید:
  ```
  C:\Users\<نام شما>\.paddleocr
  C:\Users\<نام شما>\.paddlex
  ```

بعد از یک بار دانلود موفق، دیگر نیازی به VPN یا اینترنت نیست.

## ساخت فایل اجرایی TABDIL.exe (اختیاری)

روی همان ویندوز بعد از نصب، فایل **`Build-EXE.bat`** را اجرا کنید. خروجی در پوشه
`dist\TABDIL\TABDIL.exe` ساخته می‌شود (حالت one-folder؛ کل پوشه را کپی/زیپ کنید).
روی سیستم مقصد باید Tesseract نصب باشد (یا Install.bat را آنجا اجرا کنید).

## روش کار

1. عکس‌ها را با دکمه انتخاب یا کشیدن‌ورهاکردن اضافه کنید (چند فایل هم‌زمان).
2. نوع صفحه: خودکار / جدولی تایپی / متن دست‌نویس.
3. زبان: فارسی+انگلیسی (پیش‌فرض)، فارسی، انگلیسی.
4. نوع خروجی جدولی و متنی را انتخاب کنید.
5. «شروع تشخیص» را بزنید؛ بعد از بازبینی و ویرایش، «ذخیره فایل خروجی».

## ساختار پوشه‌ها

```
windows_app/
├─ Install.bat / Run-TABDIL.bat / Build-EXE.bat / Install-PaddleOCR.bat
├─ Download-PaddleModels.bat / Check-Installation.bat
├─ run_app.py                  # نقطه ورود
├─ requirements.txt / requirements-paddle.txt
├─ TABDIL.spec                 # تنظیمات PyInstaller
├─ samples/                    # نمونه خروجی واقعی (Excel/Word)
└─ TABDIL/
   ├─ app.py                   # رابط کاربری
   ├─ ocr.py                   # موتورهای OCR
   ├─ orientation.py           # تشخیص چرخش و برش جدول
   ├─ preprocess.py            # بهبود عکس
   ├─ table.py                 # تشخیص خطوط و ساخت جدول
   ├─ exporter.py              # ساخت Excel/Word با فونت Calibri
   ├─ assets/                  # آیکون و لوگو
   └─ tessdata/                # داده زبان فارسی، انگلیسی، OSD
```

## عیب‌یابی سریع

- **برنامه باز نمی‌شود:** `Check-Installation.bat` را اجرا کنید. اگر خطای `numpy` یا `cv2` دیدید، `Install.bat` را دوباره اجرا کنید.
- **Tesseract پیدا نشد:** `Install.bat` را دوباره اجرا کنید یا دستی از https://github.com/UB-Mannheim/tesseract/wiki نصب کنید.
- **PaddleOCR هنگ می‌کند:** VPN روشن کنید و `Download-PaddleModels.bat` را اجرا کنید. یا موتور را روی «سبک (Tesseract)» بگذارید.
- **خروجی خالی است:** عکس را با کیفیت بهتر و نور یکنواخت بگیرید، گزینه «بهبود کیفیت» را روشن بگذارید.
